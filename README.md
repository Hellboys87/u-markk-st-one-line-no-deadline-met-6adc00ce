A one-line joke excusing a missed deadline: the work was done on time, but the laptop auto-updated mid-save, deleted the finished file, and then had the nerve to ask for a rating. The program writes that single line to `entry.txt` — nothing else, no picture, no link, no second line.

## Run it

```sh
node main.ts
```

It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset).
